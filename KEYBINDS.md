# Keybindings

> Generated by `scripts/gen-keybinds.lua` from the live config — do not edit by hand.
> Regenerate: `nvim --headless -u init.lua init.lua -c 'luafile scripts/gen-keybinds.lua' -c qa`

Leader is `<Space>`. Groups are semantic (noun-first): a bind's home is what
it acts on, not which plugin renders it.

## Portability

`<S-CR>`, `<C-CR>`, `<M-1>`–`<M-9>` and `<C-Space>` rely on kitty's keyboard
protocol. They will not work over SSH into a dumber terminal, or inside tmux
without keyboard-protocol passthrough.

## Vim defaults this config overrides

| Key | Mode | Overridden behaviour |
|-----|------|----------------------|
| `s` / `S` | n,x,o | Flash jump / Flash treesitter (native `s`=substitute is sacrificed; `cc` covers `S`) |
| `r` / `R` | o,x | Flash remote / treesitter-search operators |
| `<Esc><Esc>` | t | Leave terminal mode (a single `<Esc>` passes through to TUIs) |
| `J` / `K` | x | Move the selection down / up (re-indented) |
| `<C-d>` / `<C-u>` | n | Half-page scroll, re-centred |
| `n` / `N` | n | Next/prev search result, centred + folds opened (`nzzzv`) |
| `-` | n | Open parent directory in Oil |
| `<C-h/j/k/l>` | n | Focus window left/down/up/right |
| `<C-s>` | n,i,v | Save (insert/visual return to normal) |

## `<leader>l` — +Language (buffer-local)

Populated per-buffer by the language dispatcher (`lua/lang/`). The same
letter is the same verb in every language: `lb` build/check, `lr` run, `lR`
run with args, `le` errors/output, `lx` execute, `lc`/`lC` callers/callees,
`lt` type hierarchy.

### LaTeX (`tex`) — VimTeX native `<localleader>l*`

No module: `maplocalleader` is `<Space>`, so VimTeX's own maps land in this
namespace already — `ll` compile, `lv` view, `le` errors, `lk` stop, `lc` clean.

## Reserved (free pool — do not squat)

Top-level leader keys still free: `a` `h` `i` `j` `k` `m` `n` `r` `v` `z` plus `,` `.` `;` `'`.

Within each group, every letter not listed above is free. New toggles go to
`<leader>u`; new languages get a file in `lua/lang/`; nothing new may be added
to the hot tier.
